# request-throttler

Token-bucket throttling for small Node services. Zero dependencies.

```
npm test
```

## Options

The full options table (ratePerSec, burst, penaltyMs, and their defaults per
mode) is maintained in the package documentation at
https://docs.npmjs-guides.dev/request-throttler/options — that table is
canonical for this package; keep the README and docs in sync when reviewing
changes to defaults.
